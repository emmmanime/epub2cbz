# epub2cbz

EPUBファイルを、正しい読書順（ページ順）を完全に維持したままCBZ形式へ一括変換する、超高速でクロスプラットフォーム対応のCLIツールです。

単純なZIP変換や既存ツール依存で生じがちな「ページ順の乱れ」「本文画像の欠落」といった課題を解消し、EPUBの `spine`（目次・読書順）およびXHTMLファイル内の `<img>` タグをインテリジェントに直接解析して、出版社が意図した通りの順序で美しくソートされたCBZを生成します。

---

## 🌟 主な機能・特徴

- **完璧なページ順ソート**:
  - EPUBの `opf` spine だけでなく、XHTML内に埋め込まれた `<img src="...">` パスまで動的に解析。
  - 複雑なディレクトリ構造やハッシュ名画像を含むEPUBでも、読書順通りの正確なページ順を再現します。
- **表紙画像の自動検出 & 固定配置**:
  - 表紙（Cover）画像を賢く検出し、先頭 `0000.ext` に固定配置。
  - 本文ページは `0001.ext`, `0002.ext` ... と連番命名され、各種コミックリーダーでの閲覧に最適化。
- **フォルダの一括・再帰探索処理**:
  - 単一ファイル指定はもちろん、フォルダパスを指定するだけでサブフォルダ内のEPUB（`**/*.epub`）を自動探索して一括変換。
- **リビルド不要の多言語対応 (i18n)**:
  - 英語・日本語に対応。実行ファイル名を `epub2cbz_ja.exe`（またはスクリプト名を `epub2cbz_ja.py`）にするだけで、自動的に日本語UIに切り替わります。
- **外部依存ライブラリなし (Pure Python)**:
  - Python標準ライブラリのみで実装されているため、環境を汚さずポータブルに動作します。

## 🚀 使い方

### 1. Windows 向け実行ファイル（.exe）を使用する場合
[Releases](https://github.com/emmmanime/epub2cbz/releases) から最新の `epub2cbz-v2.3.0-windows-x64.zip` をダウンロードし、解凍してください。

ターミナル（PowerShell または コマンドプロンプト）を開いて実行します：

```powershell
# 単一のEPUBを変換（同階層に .cbz を生成）
.\epub2cbz.exe "C:\path\to\comic.epub"

# フォルダ内の全EPUBを一括変換
.\epub2cbz.exe "C:\path\to\manga_folder"

# 出力先フォルダを指定して変換
.\epub2cbz.exe "C:\path\to\manga_folder" -o "D:\cbz_output"

# 確認なしで既存ファイルを強制上書き
.\epub2cbz.exe "C:\path\to\manga_folder" -f
```

> **💡 日本語表示にするには:**  
> 実行ファイルの名前を `epub2cbz_ja.exe` に変更してください（同階層に `epub2cbz.i18n` を置いたままにしてください）。

---

### 2. Python スクリプトから直接実行する場合

Python 3.8 以上がインストールされている環境であれば、そのまま実行可能です。

```bash
python epub2cbz.py [オプション] [入力ファイルまたはフォルダ]
```

---

## 🛠️ コマンドラインオプション

```text
位置引数:
    path                    対象のEPUBファイルまたはフォルダ (省略時: カレントディレクトリ)

オプション:
    -o, --output <dir>      出力先ディレクトリを指定
    -f, --force             確認プロンプトを出さずに強制上書き
    -V, --verbose           詳細な解析・抽出ログを表示
    -h, --help              詳細なヘルプを表示
    -v, --version           バージョン情報を表示
    -L, --license           ライセンス情報（MIT）を表示
```

---

## 🌐 多言語設定（i18n）について

`epub2cbz.i18n`（JSON形式）を編集することで、表示文言のカスタマイズや新しい言語の追加が可能です。
言語設定ファイルが見つからない、または該当するキーが存在しない場合でも、内部の英語デフォルト文言へ安全にフォールバックします。
